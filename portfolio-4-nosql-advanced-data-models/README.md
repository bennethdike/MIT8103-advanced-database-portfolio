# Portfolio 4: NoSQL and Advanced Data Models

## Case Study
Munchiba Hotel & Suites Reservation System

## Database Technology
MongoDB Community Server and MongoDB Compass

## Overview
This portfolio demonstrates the implementation of a
document-oriented NoSQL database for managing hotel
reservations.

The MongoDB database is named munchiba_hotel_nosql,
and the collection is named reservations.

## Practical Activities
- Created a MongoDB database and collection.
- Inserted fictional hotel reservation documents.
- Retrieved reservations using filters.
- Queried embedded payment information.
- Updated an existing reservation document.
- Verified the updated document.
- Exported reservation data in JSON format.
