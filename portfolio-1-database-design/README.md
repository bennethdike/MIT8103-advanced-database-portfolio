Portfolio 1: Database Design and Modelling

Course: MIT 8103 — Advanced Database Systems

Case Study: Munchiba Hotel & Suites Reservation System

Overview

This portfolio covers the design and modelling of a relational database for Munchiba Hotel & Suites, a fictional 30-room hotel in Imo State, Nigeria.

The database was developed using PostgreSQL and pgAdmin 4.

The system contains six main tables:

1. Guest
2. RoomType
3. Staff
4. Room
5. Reservation
6. Payment

Portfolio Evidence

This folder will contain:

- Entity Relationship Diagram (ERD)
- Relational database schema
- SQL scripts for table creation and constraints
- Database normalisation explanation
- Sample data and testing evidence

All guest, staff and hotel records used in this project are fictional.
